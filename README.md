# Проект: Прогнозирование медианной зарплаты в банковской сфере

## 1. Бизнес-анализ (Business Understanding)

### Цели и границы проекта
Главная цель проекта — создать модель машинного обучения, которая сможет точно прогнозировать медианную заработную плату кандидатов в банковском секторе. Прогноз строится на основе набора компетенций, профессиональных навыков и социальных показателей соискателей.

*   **Организационная структура:** 
    *   *Заказчик сервиса:* Банковские HR-департаменты, руководители отделов подбора персонала, линейные руководители, в обязанности которых входит поиск кандидатов на вакантные позиции.
    *   *Основной пользователь:* HR-специалисты, рекрутеры, специалисты по компенсациям и льготам (C&B), линейные руководители.
    *   *Коммуникация:* Создаются рабочие чаты, собираются контакты команды разработки и экспертов со стороны заказчика.
*   **Бизнес-цель:** Оптимизация затрат на ФОТ, ускорение процесса найма, формирование конкурентных и справедливых зарплатных предложений для кандидатов и текущих сотрудников, уменьшение оттока специалистов из компании, создание привлекательных условий для новых сотрудников, в том числе на редкие позиции.
*   **Текущие решения:** На данный момент оценка рынка чаще всего проводится вручную через стандартные отчеты или базовую аналитику. Текущий подход не устраивает долгой скоростью обработки данных и низкой точностью при учете редких комбинаций навыков. Так же страдает точность, за одинаковый набор компетенций банки предлагают разный размер оплаты труда, что влечет в себе риски оттока специалистов к конкурентам.

### 1.1 Текущая ситуация (Assessing current solution)

*   **Ресурсы и оборудование:** Проект использует доступные вычислительные мощности команды разработки. Для базовых моделей (линейная регрессия) и XGBoost на текущем объеме данных закупка нового железа не требуется.
*   **Данные и доступ:** Основным источником данных выступает платформа HeadHunter (hh.ru). Данные будут собираться через открытое API или путем парсинга открытых резюме и вакансий банковского сектора.
*   **Экспертиза:** Со стороны заказчика привлекаются ведущие HR-аналитики и руководители отделов для оценки адекватности признаков (социальных показателей и навыков) и консультаций.

#### Риски проекта и план действий по их уменьшению

1.  **Риск:** Не уложиться в сроки.
    *   *Решение:* Жесткое планирование. Использование готовых библиотек для парсинга и моделирования. Быстрое создание базовой модели (baseline).
2.  **Риск:** Малое количество или плохое качество данных с HeadHunter (пропущенные значения, нереалистичные зарплатные ожидания).
    *   *Решение:* Проведение тщательной очистки данных (EDA). Удаление аномалий. Заполнение пропусков медианными значениями или с помощью алгоритмов.
3.  **Risk:** Данные качественные, но закономерности между навыками и зарплатой в принципе отсутствуют.
    *   *Решение:* Регулярный промежуточный анализ важности признаков (Feature Importance). Привлечение HR-экспертов и руководителей отделов для добавления новых бизнес-метрик.

### 1.2 Решаемые задачи с точки зрения аналитики (Data Mining goals)

Постановка задачи переведена в технические термины машинного обучения. Мы решаем задачу **восстановления регрессии** (прогнозирование непрерывной величины — заработной платы).

*   **Метрики качества:**
    *   **MAPE (Mean Absolute Percentage Error):** Показывает среднюю абсолютную ошибку в процентах. Удобна для бизнеса, так как легко объяснить, на сколько процентов в среднем ошибается модель.
    *   **R² (Коэффициент детерминации):** Показывает долю дисперсии зависимой переменной, объясняемую моделью. Поможет понять, насколько наша модель лучше, чем простое предсказание среднего значения.
*   **Критерий успешности модели:**
    *   *Минимальный порог:* MAPE ≤ 20%, R² ≥ 0.60.
    *   *Оптимальный результат:* MAPE ≤ 15%, R² ≥ 0.75.
*   **Подход к моделированию:**
    *   *Базовая модель (Baseline):* Линейная многомерная регрессия.
    *   *Основная модель:* Градиентный бустинг XGBoost.

### 1.3 План проекта (Project Plan)

План включает в себя последовательное прохождение всех шести фаз методологии CRISP-DM:
1.  **Бизнес-анализ:** Определение целей, рисков и метрик (текущий этап).
2.  **Анализ данных:** Сбор данных с HeadHunter, изучение признаков, поиск аномалий.
3.  **Подготовка данных:** Очистка данных, кодирование категориальных признаков (соц. показатели, навыки), масштабирование.
4.  **Моделирование:** Обучение линейной регрессии и настройка гиперпараметров XGBoost.
5.  **Оценка решения:** Проверка моделей на тестовой выборке по метрикам MAPE и R², бизнес-оценка результатов.
6.  **Внедрение:** Подготовка финального отчета, сохранение весов модели для интеграции в HR-сервисы.
